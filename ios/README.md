# TH15 原生 iOS 移植

目标系统为 iOS 14 及以上，设备程序为 ARM64。此目录实现 SDL3 / GLES3 原生宿主，不使用 WebView、Wasm 或 Windows 模拟器。游戏核心来自本工作区的日文 1.00b 行为重建源码，原生设置页面使用中文。

操作：Z 射击/确认，X 灵击/返回，S 低速。可拖动画面或使用左下摇杆移动，手指出圈后仍持续移动，抬起或取消时归中；菜单可滑动选择、轻点确认、双指轻点返回。可配置双击灵击、双指低速、自动射击、自动低速、灵敏度、摇杆死区、按键大小及透明度。死区可在 0–50% 范围调节，并随设置保存。“拖拽限速”默认开启，使用原版角色速度及低速速度；关闭后直接跟随拖动目标，仍遵守战斗区域边界。摇杆沿用原版移动速度。菜单短按会保留到逻辑帧处理，原版 Key Config 可用 Z/X/S/暂停分配四个手柄动作，连接的 MFi/蓝牙手柄沿用这些绑定。设置存于 NSUserDefaults。横屏及菜单按原版 4:3 等比显示，适配 iPhone/iPad 实际窗口和安全区。竖屏将原版积分板分成左右两块放在战斗区上方，战斗区保持 384:448，两个积分栏也各自保持原比例。画面在可用区域内尽可能放大，剩余区域留黑，避免拉伸或裁掉战斗区域；触摸坐标使用同一视口换算。

开发者功能默认关闭。开启后，在普通战斗中显示 DEV 悬浮按钮，打开原生面板可使用无敌、最大分数、最大道具、满火力、补满残机/灵击、一键最大化、清除子弹及激光。面板打开时暂停游戏。无敌选项只在本次应用运行中保持，关闭开发者开关会清除；开发者开关本身保存。设置中的“输入作弊码解锁全部内容”接受 `ymgjdsh`，解锁全部角色的 Extra、练习关卡、符卡记录及全部音乐，保存到游戏成绩记录。恢复原生设置不会清除已解锁的游戏记录。

逻辑固定为 60 Hz，显示卡顿时最多补 4 帧。后台、音频中断、设置及开发者面板使用独立暂停原因，重叠时全部清除才恢复。恢复清除输入与旧音频队列，应用暂停不计入符卡/游玩计时。原生设置打开时暂时隔离 SDL 窗口的键盘通知，避免作弊码输入只接收第一个字符；面板完全关闭后恢复键盘监听与游戏。成绩、录像、章节续玩保存在应用沙盒。设置里的操作说明提供本地诊断日志分享。

私有资源放于 `.local/assets`：原始 th15.dat、fonts 二进制、music OGG 与 manifest.json。字体准备使用记录的原版字体定义和 Windows GDI；音乐保留原版 PCM 长度与循环位置，OGG 为有损编码。图标从用户 th15.exe 原资源提取。源代码包不包含原始游戏资源或字体位图。

Mac 构建：`TH15_SDK=iphoneos bash ios/build_ios.sh`。可用 TH15_DEPENDENCIES 指定 SDL 源码目录，用 TH15_ASSETS 指定私有资源目录。可用 TH15_SDL_LIBRARY 指定此前同 SDK 构建的 SDL3 静态库；必须与 CMAKE_OSX_ARCHITECTURES 匹配。最低部署目标固定 14.0。模拟器用 TH15_SDK=iphonesimulator。仅模拟器验证时启用 TH15_DIAGNOSTICS=ON；最终设备包必须 OFF。

`ios/tools/native_checks.sh` 的八组检查涵盖触控/摇杆/固定时步、重叠生命周期暂停、竖屏布局、真实角色拖拽限速及解锁记录保存。`ios/tools/package_ipa.py` 检查 ARM64、iphoneos 平台、iOS 14.0、资源清单、图标和浏览器运行时排除，进行 ad-hoc 签名并生成 IPA 与校验清单。安装途径与 TH10 相同：TrollStore，或自行使用 Apple 证书和设备描述文件重新签名；ad-hoc 签名不是普通 App Store 签名。

模拟器通过、ARM64 编译及最低系统声明，不能替代 iOS 14 真机的触摸、性能与完整通关验收。实际验证结果见 VALIDATION.md。

Build 6 增加默认关闭的自动灵击、Z/S 点击保持、No Button 和完整布局编辑。自动灵击在真实碰撞回调中调用原角色 Bomb，消耗一个库存并在死亡音效/效果前返回；没有库存、无敌、非存活状态、活动灵击、对话或录像不会触发。切换按键只在战斗中锁定，暂停、旋转、进入面板和离开战斗清除锁定。No Button 战斗中隐藏摇杆与 Z/X/S，菜单恢复；设置、暂停、DEV 和手势仍可用。布局编辑可拖动全部七个控件，横竖屏分别保存，支持当前方向重置和取消，编辑使用独立暂停原因。

可重建资源流程见 ASSETS.md。新增原生检查涵盖 Toggle 捕获/释放、坐标边界和自动灵击的库存/状态/失败服务。诊断版 `--autobomb-checks` 在实际 PlayerCollision.circle 路径中注入碰撞，覆盖四角色普通 Bomb、单次消耗、保护期间不重复、关闭开关和无库存仍受击；该入口不会进入最终设备包。

Build 7 修复铃仙撞盾中断拖拽：待定受击状态保留当前手指，期间不输出移动，盾恢复后同一根手指继续移动；真正死亡、抬起、取消及离开战斗仍清除输入。限速和不限速均覆盖。显示改为等比适配，并在每个逻辑帧同步画面来源和目的视口，避免菜单/战斗切换短暂使用旧比例。
